# Atril — versión web

Cuaderno de estudio musical de Alfredo Tabernero Martínez. Abre https://alfredotabernero-arch.github.io/atril-web/ en Safari (iPhone o iPad) y elige Compartir › Añadir a pantalla de inicio.

Este repositorio solo contiene el programa publicado; los datos de cada músico se quedan en su dispositivo.
